# Tee (framework repo)

Canonical agent skill pack: **[skill/SKILL.md](skill/SKILL.md)**.

Apps created with `create-tee` get a copy of that pack plus `CLAUDE.md` / `AGENTS.md` that point at it.

When changing public APIs, update the matching file under `skill/` and the index in `skill/SKILL.md`. Do not invent APIs in docs.
