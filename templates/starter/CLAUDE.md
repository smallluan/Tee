# Tee app

This project uses **Tee** (`tee-framework`). It is not React, Vue, or Svelte.

Before you write or change any `.tee` file, open the skill pack:

1. **[skill/SKILL.md](skill/SKILL.md)** — index
2. Only the topic file that matches the task

Do not invent APIs. If the pack does not describe it, Tee does not have it.

Hard rules: `setup` runs once; state lives on `self`; lists use `<For>`; events use `t-on:`; styles are `import "./x.less"`.
